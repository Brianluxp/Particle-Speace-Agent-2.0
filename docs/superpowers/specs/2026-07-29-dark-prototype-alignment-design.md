# 粒子空间深色原型统一设计

## 目标

在不改变现有 React 路由、Mock API 边界和异步任务流程的前提下，将前端四个页面统一为原型中的深色工业工作台风格，并重点还原首页的布局和内容。

## 范围

- `/`：按照原型重建项目工作台首页。
- `/projects/new`：保留创建项目功能，接入统一深色应用框架。
- `/tasks/:taskId`：保留轮询、进度、失败重试和完成跳转，接入统一深色应用框架。
- `/models/:taskId`：保留模型预览、空状态、错误状态、全屏和下载，接入统一深色应用框架。
- 顶部产品名统一改为“粒子空间”。
- 不接入真实三维生成服务，不修改四个 API adapter 接口。

## 视觉系统

统一使用原型的核心色值：

- 页面背景：`#061321`
- 一级卡片：`#0a1a2a`
- 二级卡片：`#0d2134`
- 三级表面：`#10273c`
- 边框：`rgba(157, 194, 221, 0.15)`
- 主文字：`#dce8f4`
- 次文字：`#7f98ad`
- 青色强调：`#1dcdd0`
- 蓝色主按钮：`#1687ff`
- 警告色：`#ffac21`
- 成功色：`#27d5a0`

四个页面共享顶部栏、左侧导航栏、内容背景、卡片边框、圆角、按钮和状态颜色。导航根据当前路由显示激活状态。

## 首页结构

首页按原型组织为：

1. 顶部介绍区：
   - `Agent 3D 制作工作台`
   - `把图纸和图片，变成可运行的3D`
   - 原型说明文案
   - `创建新项目`按钮
2. 输入方式区：
   - CAD 图纸生成 3D
   - 产品图片生成3D
   - 导入现有3D模型
3. 阀门执行器视觉区：
   - 使用本地 `valve-actuator-viewport.png`
   - 展示“AI结构识别”和“运动关系”标签
   - PNG 始终作为图片，不作为模型地址
4. 最近项目区：
   - 阀门执行器
   - 四冲程发动机
   - BMX车架
   - 展示类型、状态、进度和时间

输入卡片继续通过现有路由跳转到 `/projects/new?type=<type>`，最近项目继续跳转到相应任务详情。

## 其他页面

创建页、任务页和模型预览页没有单独原型图，因此保留现有信息结构和中文业务文案，仅统一为深色工作台视觉。任务状态和模型状态必须保持真实语义，不用静态展示覆盖 API 返回结果。

## 数据处理

- 最近项目种子数据调整为符合首页原型的展示内容。
- 独立保留一个失败任务，继续用于失败状态和重试流程。
- 页面仍只能依赖 `projectApi`，不在组件内新增 Mock 业务逻辑。
- `VITE_DEMO_GLB_URL` 未配置时继续显示明确空状态。

## 验证

- 在修改行为前补充或调整测试。
- 验证首页三张输入卡片及其查询参数跳转。
- 验证最近项目展示与任务链接。
- 验证四个路由共享深色应用框架和正确导航状态。
- 保持任务推进、失败重试、模型预览和空状态测试通过。
- 运行全部 Vitest 测试和生产构建。
- 在本地浏览器检查四个路由的背景、布局、溢出和交互。

## 不包含

- 不新增账号、支付、多人协作或模型编辑能力。
- 不引入组件库、Three.js 或 react-three-fiber。
- 不改造 API adapter 为真实后端。
- 不将原型 HTML 以 iframe 或静态页面方式嵌入 React 应用。
